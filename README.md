## Projects

### MY SIZE

衣類のサイズ選びをサポートするWebアプリケーションです。

オンラインで服を購入するときの「サイズが合うか分からない」という悩みを解決することを目的として制作しました。

#### Features

- ユーザー登録・ログイン
- サイズ情報の登録
- 商品検索
- カテゴリ・ブランドによる絞り込み
- 登録したサイズとのマッチ度表示
- お気に入り商品の保存
- MY CLOSET
- 商品詳細表示
- Supabaseによるデータ管理
- ユーザーごとのデータ管理（RLS）

#### Technology

- Next.js
- React
- TypeScript
- Tailwind CSS
- Supabase
- Git / GitHub
- Vercel
